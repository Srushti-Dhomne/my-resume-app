# My Resume App

A simple Student Resume App made with Python and FastAPI.

## What this project does

This project stores student details like name, age and skill.
We can add, see, update and delete student data using API.

## Features - CRUD

- Create - Add new student with POST
- Read - See all students, see student by name, see students by skill with GET
- Update - Update student data with PUT
- Delete - Delete student with DELETE

## Technologies Used

- Python
- FastAPI

## How to run

1. Install FastAPI
2. Run app.py
3. Open browser and test the APIs
